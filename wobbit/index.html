Before you take one home

A few small
questions.

How do I install Wobbit?

Download the ZIP, unzip it, and open Wobbit. If macOS asks you to confirm opening an app downloaded from the internet, choose Open. The app then helps you move it to Applications on first launch. Follow onboarding to connect the coding agents you use. About opening downloaded apps.

Will it work on my Mac?

Wobbit requires macOS 15 Sequoia or later. One download supports both Apple silicon and Intel Macs.

Is Wobbit free? Do I need an account?

Yes, Wobbit is currently free, and no Wobbit account or API key is required. It reads activity from the coding agents you already have installed and use on your Mac. If paid features are ever introduced, their price and terms will be shown before purchase.

Why does Wobbit ask for folder access?

Wobbit needs access to local provider folders to read session activity. Onboarding guides you through selecting the relevant folders. Claude Code can also use local hooks for real-time signals.

Does Wobbit read my conversations?

Depending on the provider, Wobbit may read local transcript content, tool calls, and message snippets to work out what a session is doing and show context in its bubble. That processing stays on your Mac; Wobbit does not upload your sessions to a developer-operated server. Read the privacy policy.

Does every provider show the same details?

The available details depend on the provider’s local activity. Codex, Claude Code, and Cursor can gather multiple sessions. Antigravity provides local activity and status signals. Shortcuts open a specific conversation when available, or the related app.

How do updates work?

Wobbit includes an updater. You can configure automatic update checks or check manually in Settings → General. Downloads come from Wobbit’s GitHub releases.

How do I uninstall Wobbit?

If you installed Claude Code hooks, open Settings → Providers → Claude Code and choose Remove Hooks first. Turn off Start at Login in General settings, quit Wobbit, then move Wobbit from Applications to the Trash. Your coding-agent conversations remain in their provider folders. Some Wobbit preferences may remain on your Mac.

What does “Notarized by Apple” mean?

Wobbit is signed with the developer’s Apple Developer ID and submitted to Apple’s notarization service, which checks for known malicious software. macOS can verify the developer and notarization when you open it. Notarization is a security check, not an Apple endorsement. Learn more from Apple.

A small lineageBeige plastic computers and desktop toys.

Wobbit borrows from a time when computers felt like objects with personality: warm beige plastic, translucent colors, blinking cursors, and friendly faces that made an unfamiliar machine feel approachable.

It also owes something to desktop toys and screen mates—tiny sheep, pets, and odd little creatures that wandered around your desktop. Wobbit keeps that sense of presence and gives it a modern job: making your coding agents visible at a glance.
