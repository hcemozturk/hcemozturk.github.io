About Wobbit

Wobbit is a macOS menu-bar and desktop companion developed by Huseyin Cem Ozturk (“we,” “us,” or “the developer”). It reads locally available activity from supported coding agents and presents agent and session states through glanceable Wobbit windows.

Each supported coding agent has its own Wobbit, which may represent multiple sessions from that provider.
